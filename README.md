# Aurum AI

A black-and-gold AI chatbot with two assistant modes:

- **General** — broad conversational assistant
- **Engineering** — engineering-focused reasoning with units, assumptions, verification, design tradeoffs, and safety-minded analysis

## Run locally

```bash
npm install
npm run dev
```

Create `.env.local` from `.env.example` and configure your Vercel AI Gateway model.

## Stack

Next.js App Router, TypeScript, Vercel AI SDK, Vercel-ready deployment.
